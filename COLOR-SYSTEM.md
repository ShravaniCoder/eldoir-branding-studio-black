# ELDOIR Luxury Color System

| Token | Hex | Usage |
|---|---|---|
| Obsidian Black | `#080808` | Main background, hero, footer |
| Deep Espresso | `#151210` | Major sections |
| Graphite | `#202020` | Cards, panels, secondary dark surfaces |
| Soft Ivory | `#F0EBE2` | Headings and primary text |
| Mushroom Taupe | `#81776B` | Secondary text, metadata |
| Antique Champagne | `#A88B5E` | Luxury accents, borders, buttons, numbers |

The interface intentionally keeps champagne restrained so it reads as a premium accent rather than a bright theme colour.
